### 3.14.1 Apply as Mentor

3.14.1.3.a MentorsController
Table 3.14.1.3.a: MentorsController Description Table
| No | Method | Description |
|---|---|---|
| 1 | apply(req, res, next) | Handles the POST /api/mentors/apply request and delegates to MentorMeService.applyForMentor; returns the result or an error response to the client. |

3.14.1.3.b MentorMeService
Table 3.14.1.3.b: MentorMeService Description Table
| No | Method | Description |
|---|---|---|
| 1 | applyForMentor(userId, body) | Apply for mentor. Validates the request data. Retrieves User, Mentor, Notification data. Creates/updates Mentor, Notification records. |
