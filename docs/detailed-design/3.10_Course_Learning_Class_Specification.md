### 3.10.3 Enroll Free Course

3.10.3.3.a EnrollmentController
Table 3.10.3.3.a: EnrollmentController Description Table
| No | Method | Description |
|---|---|---|
| 1 | enroll(req, res, next) | Handles the POST /api/courses/:id/enroll request and delegates to MentorCommissionService.resolveCoursePlatformFeeRate, CouponService.validateCoupon, TransferPaymentExpiryService.expireEnrollmentTransferIfNeeded, CourseStatsService.incrementCourseEnrollmentCount; returns the result or an error response to the client. |

3.10.3.3.b MentorCommissionService
Table 3.10.3.3.b: MentorCommissionService Description Table
| No | Method | Description |
|---|---|---|
| 1 | resolveCoursePlatformFeeRate(mentor, at) | Resolve course platform fee rate. |

3.10.3.3.c CouponService
Table 3.10.3.3.c: CouponService Description Table
| No | Method | Description |
|---|---|---|
| 1 | validateCoupon(options) | Validate coupon. Validates the request data. Retrieves Coupon data. |

3.10.3.3.d TransferPaymentExpiryService
Table 3.10.3.3.d: TransferPaymentExpiryService Description Table
| No | Method | Description |
|---|---|---|
| 1 | expireEnrollmentTransferIfNeeded(enrollment, options) | Expire enrollment transfer if needed. Retrieves CartOrder data. Creates/updates Payment, Enrollment records. |

3.10.3.3.e CourseStatsService
Table 3.10.3.3.e: CourseStatsService Description Table
| No | Method | Description |
|---|---|---|
| 1 | incrementCourseEnrollmentCount(courseId, session) | Increment course enrollment count. Creates/updates Course records. |
