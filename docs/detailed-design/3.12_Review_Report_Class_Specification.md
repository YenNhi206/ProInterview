### 3.12.1 Write Review

3.12.1.3.a BookingsController
Table 3.12.1.3.a: BookingsController Description Table
| No | Method | Description |
|---|---|---|
| 1 | createReviewForBooking(req, res, next) | Handles the POST /api/bookings/:id/review request and delegates to ReviewsService.createReview; returns the result or an error response to the client. |

3.12.1.3.b ReviewsService
Table 3.12.1.3.b: ReviewsService Description Table
| No | Method | Description |
|---|---|---|
| 1 | createReview(userId, body) | Create review. Validates the request data. Retrieves Mentor, Course data. Creates/updates Review, Booking records. |

### 3.12.2 Reply to Review

3.12.2.3.a ReviewsController
Table 3.12.2.3.a: ReviewsController Description Table
| No | Method | Description |
|---|---|---|
| 1 | reply(req, res, next) | Handles the PATCH /api/reviews/:id/reply request and delegates to ReviewsService.replyToReview; returns the result or an error response to the client. |

3.12.2.3.b ReviewsService
Table 3.12.2.3.b: ReviewsService Description Table
| No | Method | Description |
|---|---|---|
| 1 | replyToReview(mentorUserId, reviewId, body) | Reply to review. Validates the request data. Retrieves Mentor, Review data. Saves the updated record. |
