### 3.20.1 Resolve Report

3.20.1.3.a AdminController
Table 3.20.1.3.a: AdminController Description Table
| No | Method | Description |
|---|---|---|
| 1 | updateReport(req, res, next) | Handles the PATCH /api/admin/reports/:id request and delegates to ReportsService.updateReportStatusForAdmin; returns the result or an error response to the client. |

3.20.1.3.b ReportsService
Table 3.20.1.3.b: ReportsService Description Table
| No | Method | Description |
|---|---|---|
| 1 | updateReportStatusForAdmin(adminUserId, reportId, body) | Update report status for admin. Validates the request data. Retrieves Report data. Creates/updates Notification records. |
