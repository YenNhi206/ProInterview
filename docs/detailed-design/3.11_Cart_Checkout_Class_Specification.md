### 3.11.1 Add Course to Cart

3.11.1.3.a CartService
Table 3.11.1.3.a: CartService Description Table
| No | Method | Description |
|---|---|---|
| 1 | addCartCourse(userId, courseId) | Add cart course. Validates the request data. Retrieves Course, Enrollment, Cart data. Creates/updates Cart records. |

Table 3.11.2.3.a: CartService Description Table
| No | Method | Description |

Table 3.11.3.3.b: CouponService Description Table

### 3.11.4 Checkout Cart

3.11.4.3.a CartService
Table 3.11.4.3.a: CartService Description Table
| No | Method | Description |
|---|---|---|

### 3.11.5 Cancel Order

3.11.5.3.a CartService
Table 3.11.5.3.a: CartService Description Table
| No | Method | Description |
|---|---|---|
| 1 | cancelCartOrder(userId, orderId) | Cancel cart order. Validates the request data. Retrieves CartOrder data. Creates/updates Cart, CartOrder records. |
