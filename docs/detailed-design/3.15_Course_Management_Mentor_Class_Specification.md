### 3.15.4 Delete Course

3.15.4.3.a CoursesController
Table 3.15.4.3.a: CoursesController Description Table
| No | Method | Description |
|---|---|---|
| 1 | archive(req, res, next) | Handles the DELETE /api/courses/:id request and delegates to CourseArchivePolicyService.getCourseArchiveEligibility, CourseArchivePolicyService.removeArchivedCourseFromCarts; returns the result or an error response to the client. |

3.15.4.3.b CourseArchivePolicyService
Table 3.15.4.3.b: CourseArchivePolicyService Description Table
| No | Method | Description |
|---|---|---|
| 1 | getCourseArchiveEligibility(course, now) | Get course archive eligibility. Retrieves Enrollment, CartOrder data. |
| 2 | removeArchivedCourseFromCarts(courseId) | Remove archived course from carts. Creates/updates Cart records. |
