### 3.2.1 View Profile

3.2.1.3.a AuthController
Table 3.2.1.3.a: AuthController Description Table
| No | Method | Description |
|---|---|---|
| 1 | me(req, res, next) | Handles the GET /api/auth/me request and delegates to AuthService.getMeUser; returns the result or an error response to the client. |

3.2.1.3.b AuthService
Table 3.2.1.3.b: AuthService Description Table
| No | Method | Description |
|---|---|---|
| 1 | getMeUser(userId) | Get me user. Validates the request data. Retrieves User data. |

### 3.2.2 Update Profile

Table 3.2.2.3.a: AuthController Description Table
| No | Method | Description |
|---|---|---|

Table 3.2.2.3.b: AuthService Description Table
| No | Method | Description |
