### 3.17.1 Approve / Reject Course

Table 3.17.1.3.a: AdminController Description Table
| No | Method | Description |
|---|---|---|

### 3.17.3 Create / Import Questions

3.17.3.3.a ModeratorController
Table 3.17.3.3.a: ModeratorController Description Table
| No | Method | Description |
|---|---|---|
| 1 | createQuestion(req, res) | Handles the POST /api/moderator/questions request and delegates to QuestionBankService.createQuestion; returns the result or an error response to the client. |
| 2 | bulkQuestions(req, res) | Handles the POST /api/moderator/questions/bulk request and delegates to QuestionBankService.bulkUpdateQuestions; returns the result or an error response to the client. |

3.17.3.3.b QuestionBankService
Table 3.17.3.3.b: QuestionBankService Description Table
| No | Method | Description |
|---|---|---|
| 1 | createQuestion(options, moderatorId) | Create question. Validates the request data. Retrieves QuestionBank data. Creates/updates QuestionBank records. |
| 2 | bulkUpdateQuestions(options, moderatorId) | Bulk update questions. Retrieves QuestionBank data. Creates/updates QuestionBank records. |
