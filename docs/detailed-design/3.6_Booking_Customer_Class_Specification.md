### 3.6.1 Book Mentor

3.6.1.3.a BookingsController
Table 3.6.1.3.a: BookingsController Description Table
| No | Method | Description |
|---|---|---|
| 1 | create(req, res, next) | Handles the POST /api/bookings request and delegates to BookingsService.createBooking; returns the result or an error response to the client. |

3.6.1.3.b BookingsService
Table 3.6.1.3.b: BookingsService Description Table
| No | Method | Description |
|---|---|---|
| 1 | createBooking(userId, body) | Create booking. Validates the request data. Retrieves User, Mentor, Booking data. Creates/updates Booking records. |
